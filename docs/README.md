# Pagenova documentation site

This is a dependency-free static documentation site. Open `docs/index.html` in
a browser for a quick local preview, or run the project's Vite server and visit
`/docs/`.

For GitHub Pages, publish this `docs/` directory. All links and assets are
relative, so the site works from a project page such as
`https://<account>.github.io/<repository>/`.

Before a public release, replace the CSS product illustration with current
Pagenova screenshots. Do not use screenshots that expose private pages, API
keys, conversations, or extension IDs.
