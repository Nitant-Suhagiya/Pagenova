# Pagenova documentation site

This is a dependency-free static documentation site. Open `docs/index.html` in
a browser for a quick local preview, or run the project's Vite server and visit
`/docs/`.

For GitHub Pages, use `main` and `/docs` as the publishing source. All links
and assets are relative, so the site works from a project page such as
`https://<account>.github.io/<repository>/`.

The portal uses the real Pagenova logo and a static interface illustration.
Keep it free of private pages, API keys, conversations, extension IDs, and
other user data.
