Support

Start with the documentation, then open a GitHub issue if the problem remains. Please do not include API keys, private documents, or sensitive screenshots.

Open a GitHub issue →Troubleshooting guide

Report a problem

Include the Pagenova version, browser and version, operating system, selected provider/model, the action you took, and the exact error message. Remove API keys, personal information, private page content, and screenshots that reveal sensitive data before posting.

Before filing an issue

  1. Reload the extension from your browser's extensions page if you are testing a new build.
  2. Confirm the selected provider works directly, such as checking that Ollama is running.
  3. Read the relevant troubleshooting section in the documentation.

Privacy questions

For questions about the privacy policy or data handling, use the same issue tracker. Do not post private content or credentials. See the privacy policy for the data flow Pagenova uses.
